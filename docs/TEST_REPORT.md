## 验证边界

- 后端测试实际运行 FastAPI ASGI 应用及 SQLAlchemy SQLite；前端交互测试在 jsdom 中使用本项目 API 的测试响应。未模拟任何第三方平台。
- 环境缺少可用的浏览器预览工具，未执行真实浏览器视觉、移动设备、PWA 安装或浏览器网络离线验收。
- PostgreSQL 驱动和数据库 URL 已支持，但没有可用 PostgreSQL 实例，未进行实库兼容性测试。
- pytest 有 1 条 Starlette 对 AnyIO BlockingPortal 别名的弃用提示，无测试失败。
- `npm audit` 的零漏洞结果仅代表当次 npm 审计结果，未对 Python 依赖执行同类审计。
