# 第一阶段实施记录

每项功能在进入下一项之前运行对应测试；最终运行完整回归及生产构建。

1. 前后端结构：React + TypeScript + Vite，FastAPI，项目内 Python venv。
2. 消息接入：仅手工提交 / 自有 API，不实现第三方平台连接器。
3. 原文存储：SQLAlchemy + SQLite，支持 PostgreSQL URL，禁止原文修改。
4. 通知解析：本地确定性规则，结果需要人工核对。
5. 任务管理：创建、编辑、状态流转。
6. 来源追溯：通知 → 全部原始消息 → 来源标识 / 时间 / URL。
7. 去重合并：仅正文规范化后完全一致的消息合并；不自动模糊合并。
8. 可视化管理：仪表盘、消息、通知、任务和 PWA 应用壳。

测试输入均为项目自身测试夹具，不代表任何真实平台或用户数据。
